ข้อจำกัดของแอป LINE (แก้ที่ต้นเหตุไม่ได้)

Android ใน LINE ยังมี 2 จุดที่ติด

เกิดจากพฤติกรรมของ LINE บน Android — เปิดด้วย Chrome แล้วใช้งานได้ปกติ

รายการ #1

ปัดปิดหน้า LIFF ไม่ได้

  • เปิดลิงก์ใน LINE แล้วปัดปิดหน้าต่างไม่ได้
  • เปิดด้วยเบราว์เซอร์ (Chrome) ใช้งานได้ปกติ
แนวทาง: กดปุ่ม «ปิดหน้าต่าง» หรือใช้ปุ่มเปิดด้วย Chrome
รายการ #2

กดถ่ายรูปแล้วเปิดคลังรูป

  • บางเครื่องกดถ่ายรูปแล้วเปิดแกลเลอรีแทนกล้อง
  • เปิดด้วย Chrome แล้วใช้งานได้ปกติ
แนวทาง: ใช้โหมดถ่ายในหน้า LIFF (ถ้ามี) หรือเปิดด้วย Chrome

แนวทางปฏิบัติสำหรับช่าง

แนะนำ: เปิด Check-In / Out ด้วย Chrome

มีปุ่มลิงก์ในระบบให้เปิดหน้า Check-In / Check-Out ด้วย Chrome ได้โดยตรง

ถ้าเปิดใน LINE

อาจเจอปัญหา

  • ตำแหน่ง GPS คลาดเคลื่อนบนบางเครื่อง
  • ถ่ายรูปแล้วเปิดคลังรูปแทนกล้อง
  • ปัดปิดหน้า LIFF ไม่ได้
ถ้าเปิดด้วย Chrome

ใช้งานได้ราบรื่นขึ้น

  • ตำแหน่งแม่นยำขึ้น
  • เปิดกล้องถ่ายได้โดยตรงมากขึ้น
  • ปิดหน้าต่างได้ตามปกติ
ขั้นตอน 1

กดลิงก์ Check-In / Out

จากข้อความใน LINE ตามปกติ

ขั้นตอน 2

กดปุ่มเปิดด้วย Chrome

มีปุ่มในหน้าให้ย้ายไป Chrome ได้เลย

ขั้นตอน 3

ใช้งานจนเสร็จแล้วปิด

ตำแหน่งและกล้องทำงานเสถียรขึ้น
